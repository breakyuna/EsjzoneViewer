# Debug 日志模式

在「设置 → 诊断 → Debug 日志模式」切换。默认关闭，切换即时生效，选择保存在现有
Settings DataStore 的 `debug_logging` 中；应用重启后在基础服务初始化前恢复。
Release APK 同样可开启，不依赖 `BuildConfig.DEBUG`，不启用 WebView 远程调试。
关闭后停止新增详细追踪，已记录内容保留，原有普通日志继续记录。

## 一次复现的记录范围

- 环境：版本、提交 ID、构建时间、进程编号、Android／设备及 WebView 版本。
- HTTP：每个调用的独立编号、所属页面请求编号、队列、代理类型、DNS 结果、连接、TLS、
  连接复用、请求／响应头阶段、请求／响应字节数、响应状态、跳转目标、取消与异常。
  每个事件包含自调用开始及距上个事件的耗时。覆盖 ESJ、文库、图片、字体和更新检查客户端。
- 页面请求：并发许可等待、请求合并、缓存命中、旧缓存返回、后台刷新、校验及错误回退。
  HTML 仅记录长度、固定 DOM 标记与选择器计数；文库详情缺少字段时记录固定 XPath。
- 全部应用 WebView：独立浏览器编号、主文档／资源地址及允许状态、加载进度、实际／原始地址、
  挂载和尺寸、可见性、页面提交／完成、HTTP／SSL／资源错误、渲染进程退出、JS 错误类型。
  文档采样包含 readyState、编码、正文长度、登录控件与隐藏／额外控件计数、禁用／归属异常数量、
  有效时长选项数量、POST／enctype／action 校验标记和脱敏 action。
- 文库登录：创建与重新绑定、Cookie 恢复、点击打开网页／返回原生／重新打开／提交／退出、
  文档与挂载代际、被忽略的旧回调、表单拒绝原因、超时、会话核对结果。
  隐藏传输另外记录锁等待、会话关闭原因、Cookie 恢复、脚本耗时、空文档等待与销毁。
- Cookie：只记录恢复／读取／更新／桥接的数量、作用域地址、是否发生过期清理和代际变化。
- UI／本地状态：导航动作与页面种类、ViewModel 状态种类、设置名称及读写阶段、数据库 SQL 操作种类、
  已知表名与绑定参数数量。不记录状态对象内容、数据库绑定值或 SQL 原文。

HTTP 事件通过 [OkHttp EventListener](https://raw.githubusercontent.com/square/okhttp/parent-5.4.0/okhttp/src/commonJvmAndroid/kotlin/okhttp3/EventListener.kt)
观察，不读取请求／响应正文或改变重试行为。WebView 观察沿用
[WebViewClient 回调](https://developer.android.com/reference/android/webkit/WebViewClient)，
不改变来源限制、证书拒绝策略、验证码操作或登录提交方式。
`onPageFinished` 与 `onPageCommitVisible` 是不同阶段，日志不把加载回调当作登录成功或视觉验收。

## 保留与导出

Debug 模式内存保留最近 2,000 条，磁盘每份最多 8 MiB，当前文件和三份归档共约 32 MiB；
普通模式内存仍保留 500 条，单文件最多 2 MiB。另保留最近一次崩溃报告。
记录超长时保留头尾并标注截断；容量耗尽后最旧归档轮换删除，日志不是无限历史。

复现后到「设置 → 系统日志 → 分享日志」导出文本文件。导出先等待已接受的日志写入，
按最旧归档到当前日志的顺序包含磁盘记录及最近崩溃报告，包含重启前仍保留的记录。
读取、合并在后台进行；分享使用只读、限于日志导出目录的 FileProvider URI，
不通过 Intent 的 EXTRA_TEXT 发送大型日志。缓存中仅保留最近两份导出文件。

「复制当前日志」只复制有大小限制的近期内存窗口；完整复现诊断请使用文件分享。
ESJZone／Wenku8、级别和关键词筛选继续有效，文件导出包含全部来源和级别。

## 脱敏与验证边界

不记录账号、密码、Cookie／Token 值、认证头内容、表单字段值、原始 JS 回调、HTML 或小说正文。
URL 仅保留已知路径结构、数字 ID 与查询参数名；查询值、用户信息、fragment 和任意路径词条过滤。
控制台仅记录级别、错误种类、行号与脱敏脚本来源，不收集任意 console message。
统一日志入口再次过滤常见凭据字段与异常中的 URL；导出旧记录也重新脱敏。

日志提供已覆盖阶段的证据，无法保证任何未来缺陷都能仅靠日志定因。首次文库空白仍需新版本设备复现，
本次没有真实账号／实站／设备登录验收。新增 JVM 脱敏与结构摘要用例、设备设置持久化用例源码；
默认只执行静态检查，不据此宣称测试、编译、Lint、APK 或设备验证通过。
