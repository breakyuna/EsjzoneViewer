# 双站页面融合

ESJZone 与文库8共用首页、搜索、分类、书架和个人工具的页面结构。来源选择只控制展示，
不会改写站点域名、作品身份、账号作用域或下载任务的请求地址。

## 页面与状态

- 首页使用相同的发现标题、搜索／分类按钮、来源分段控件。两站列表分别保存滚动状态。
- 首页来源作为新搜索／分类页面的默认值；搜索和分类在同一导航 entry 内切换来源，并更新
  最近发现来源。已有搜索／分类 entry 保持自己的选择；返回首页展示最近发现来源。
- 搜索复用关键词和历史。ESJ 分类／排序与文库书名／作者模式分别保留。再次提交同一关键词
  刷新当前来源；切换来源不会新增返回层级。
- 文库首页只展示首页分区。全部、完结、动画化、新书、更新和总／日／月排行在统一分类页面
  直接切换，沿用现有候选接口和解析，不新增站点能力假设。
- 书架在底部 Tab 内切换，分别保存分组、排序、视图和滚动状态，仍使用原有独立书架作用域。
  编辑／删除期间不切换来源。ESJ 保留同步，文库保持本地书架。
- 本地历史、下载和书签提供全部／ESJZone／文库8筛选与来源标记，筛选独立于发现来源。
  批量选择、删除只针对当前可见结果；编辑期间不能切换来源。ESJ 云端历史单列标明站点。
- 详情用来源标签标识作品，阅读、目录、导出、下载及评论支持范围沿用作品本身的来源。
- 我的页面集中两站账号入口。ESJ 管理沿用设置；文库进入原生登录／核对页面。
  文库状态只展示本次进程观察到的登录结果，未核对时不根据 Cookie 存在推断已登录；
  不在我的页面自动发起登录检查，不持久化这一展示状态。
- 登录或验证完成后回到原列表刷新。已有 Wenku8Page／Wenku8BookshelfPage 路由仍可恢复，
  日常入口不再通过这些独立聚合页面。

## 视觉

来源控件共用 Material 3 分段按钮、项目字体和间距。来源标记使用主题语义色和文字；
两站共用作品卡片，适配浅／深色主题。浮动底栏下保留列表底部空间。

## 验收边界

本次只允许静态检查，不运行编译、JVM 测试、Lint、APK 构建或设备测试。
新增 LibrarySourceTest 源码覆盖混合列表筛选、重复数字 ID、旧章节书签及相似域名判定。
设备验收需检查：切换不叠加返回层级、分页与滚动恢复、搜索模式与关键词保留、筛选后的
批量删除范围、登录返回刷新，以及窄屏／大字体／深浅主题／浮动底栏的布局。
