## 已实现

1. 下载列表可打开本地目录，按本地记录继续阅读；仅正文已保存的章节也可读，目录区分完整下载、正文保存及未下载。删除只在编辑模式显示；本地目录可暂停或继续后台下载，继续下载是明确的联网操作。目录路由支持 Navigation 3 恢复。
2. 首页刷新失败保留内容并显示重试；一周更新失败保留旧列表，提供独立重试。
3. 取消启动、登录、切换镜像时的社区预取。热门详情仅补全可见轮播附近两项，串行且可取消；后台 HTML 刷新及热门补全最多占一个请求槽，排队中的前台请求优先，总请求上限仍为六。不会中断已经执行的请求。相邻章节预读保留。
4. 封面使用低对比度占位及图片局部重试，已有成功图片在替换失败时保留；不刷新整页。头像、正文图片等不随封面调整而改写策略。
5. 历史记录减轻背景装饰、缩小封面；统计排名移除整块主题色和排名色块；下载删除操作退出普通浏览状态。保留主题、详情头图及既有宽屏布局。
6. 搜索增加本地/站点切换。本地合并下载清单、阅读历史和当前账户书架，按标题匹配，合并镜像重复作品，保留已知成人标记。下载结果打开本地目录，历史结果继续阅读，仅书架元数据的结果打开详情。切回站点才执行站点搜索，输入本身不触发请求。
7. 阅读目录支持章节名搜索、定位当前章节及本地保存状态。前后章节加载失败后保留正文，滚动与分页模式均提供边界重试；停止失败后的自动循环请求，显式重试恢复加载。
