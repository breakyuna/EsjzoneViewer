# 动效改造与验收

基线：master `bd923c95b016e83b42d9a9987ce98dcb8726377d`。

## 已实现

- `AppMotion` 统一用途明确的 tween / spring 参数，不依赖 Material3 1.4.0 的 internal MotionScheme。
- `AppTheme` 监听三个系统动画倍率，实时提供 `LocalReduceMotion`；原有 composable helper 统一读该来源。
- 轮播在减少动态或 TalkBack 触摸探索开启时停止自动播放，设置变化会取消正在执行的自动播放协程。
- shimmer、Lottie、呼吸点、幽灵漂浮在所属页面未 RESUMED 或减少动态时显示静态状态。
- 页面进入保持旧页静止，退出与进入对称；预测性返回按手势边缘缩放、轻移，容器变换/圆形揭示继续使用原分流。
- Loading/Login/Main 认证闸门使用 fade-through；共享封面与普通导航保留相同的 360ms 时长和曲线。
- 阅读器上下工具栏、阅读设置和亮度面板统一 spring；工具栏圆角平滑变化。
- 收藏按钮颜色、文案、图标过渡；弹跳只消费用户添加收藏事件，取消收藏或减少动态会取消并复位，不改变本地优先同步逻辑。
- 简介高度和箭头旋转；书签/划线、评论分页、小说列表布局切换加入过渡，滚动状态移到过渡外层。
- 评论回复目标过渡、新评论一次性高亮；评论输入栏继续实时上报高度，保持下方内容避让。
- 社区、分类、小说列表、个人资料、会员状态加入过渡；结果刷新按状态类型保留组合。旧内容退场期间不响应指针，也不重复暴露可访问性语义。
- `AsyncImage` 路径使用短 crossfade；`execute() + Image` 缓存封面不套用无效的 Coil painter 过渡，也不因减少动态变化重新发出请求。
- 阅读器正文仅在原导航结束和定位完成门槛之后淡入，冻结背景始终留在正文下方；加载 spinner 保留原有首帧策略。
- 全屏通用 loading 延迟显示，登录错误展开/收起，Tab 内容 fade-through，导航选中态使用 effects spring。
- 下载列表改为带跨列统计项的 LazyVerticalGrid，使下载卡片成为直接 lazy item，按书籍 key 动画。
- 阅读器 FADE 使用 fade-through，COVER 添加只在绘制阶段读取进度的阴影和下层暗化。
- 设置分区在宽屏使用 fade-through，竖屏保留有方向的导航，统一时长参数。

## 保留与取舍

- 系统 targetSdk 规则不能证明所有设备都会显示应用内部预测性返回动画。
- 最终 Compose 依赖解析版本未执行 Gradle 核实，不将本机缓存存在某版本视为解析结果。
- 不将加载/结果硬切直接认定为已实测的一帧空白。
- 不强迫不同用途的动画使用同一个时长。
- 不增加登录失败抖动、轮播卡片缩放或仿真卷页。
- 共享封面卡片不增加整卡按压缩放，避免改变共享元素的起始画面。
- 设置分区暂不另加 PredictiveBackHandler：嵌套 navigationevent dispatcher 的共存行为尚无真机验证。
- 其余 `adaptiveItems` 页面保留按行布局，不在本次动效调整中迁移所有列表容器。

## 真机验收

1. 在页面保持打开时切换系统“移除动画”；确认轮播立即停止、静态装饰生效，恢复后可继续播放。
2. TalkBack 开启/关闭触摸探索，手动滑动轮播后前后台切换，不应抢焦点或自动跳页。
3. 四个 Tab 快速来回切换；确认底栏稳定、旧页不可点击，历史图标只在选中时旋转。
4. 普通详情、共享封面、圆形揭示、阅读器分别测试返回完成和手势取消；左右边缘都测试，重点观察底栏、封面及阅读器画面锁定。
5. 冷启动自动继续阅读、慢网络/离线继续阅读、定位重试；确认进入动画期间画面不变、正文准确定位后才显现，退出无额外加载页。
6. 工具栏与阅读设置/亮度面板快速反复开关；确认正文位置、底部高度和系统栏稳定。
7. 收藏/取消快速连点，再制造同步失败；本地收藏意图应保留，弹跳不重放，失败文本正确。
8. 简介展开/收起并加载富文本图片；评论翻页、回复/取消、新发评论；检查输入栏和高亮。
9. 书签/划线和列表/网格来回切换、删除项目；检查各布局滚动状态及分页只由当前布局触发。
10. 大字号、横屏、宽屏、冷缓存和命中缓存分别检查；下载删除逐项动画不应整行误闪。

本地仅进行源码/API 核对、Kotlin 语法解析、资源/引用静态检查和 `git diff --check`。
没有运行 Gradle、编译、测试、Lint 或设备验收；未提交至 GitHub。
