## 资源预算与兼容性

- ZIP 本次处理量上限为 16 GiB 或当时可用磁盘减 64 MiB，取较小值；条目数继续限制为 200,000。
- `backup.json` 磁盘提取及单个下载 JSON 解压流最多 32 MiB；JSON 文本最多 16 Mi 个 UTF-16 单元，嵌套 64 层、500,000 个 token、每个集合 50,000 项、单字符串 4 Mi 个单元、键 512 个单元、数字 128 个字符。
- 替换规则最多 128 条，模式 512 个单元、目标 4,096 个单元；每个文本片段最多 131,072 个单元，输出最多 262,144 个单元，匹配最多 4,096 次，并限制模式程序规模及合计匹配工作预算。超预算片段保持原文，避免展示部分替换结果及破坏偏移。
- RE2/J 不支持前后查找与模式内反向引用；旧规则文字仍可编辑，无法编译的规则跳过并显示错误。目标中的 `$1`、`${name}` 捕获组替换及反斜杠转义继续支持。
- 网页转换单次最多 32,768 个单元，每个浏览器实例累计最多 4 Mi 个单元或 4,096 次调用；网页不能选择与用户当前模式不同的转换。导航不会重置累计额度；用尽后保持原文。
- 图片响应最多 32 MiB；普通图片总调用时限 60 秒，Wenku 保留现有 120 秒；开始读取及每约 1 MiB 检查一次至少 64 MiB 可用空间。

以上限制可能拒绝超大历史备份、超长段落/规则或超大图片。正常格式、书籍作用域以及备份事务/临时目录回滚策略保留。
