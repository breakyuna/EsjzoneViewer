# 本地内容与存储性能优化（2026-11-03）

基于 `newui / c3dc709`，对应 [性能审查](../audit/PERFORMANCE-2026-11-03.md) 的 F01–F12。以下描述源码中的行为变化；提交前尚未通过编译、自动化测试或真机性能验收。

## 修改对应表

| 审查项 | 本次实现 |
| --- | --- |
| F01 书架首屏门控 | 复用独立的 Room 发布与进度校正流程，先构建基础阅读索引；存储校正失败保留列表。跨协程结果发布受锁保护，旧结果不能盖过新的阅读位置。 |
| F02 历史主线程读盘 | 模型构造只读云端历史内存快照；磁盘恢复在加载协程中执行，恢复后检查取消与加载代际，再开始网络刷新。 |
| F03 下载全书预检 | 选章下载不读取未选章节正文；目标章节的校验结果复用于首次清单提交。预检期间有新提交时保留其较新状态，避免覆盖并发阅读自动保存。 |
| F04 下载全局长锁 | 清理提示改为短路存在性检查。精确大小在锁外统计；删除先登记删除状态及代际，锁外递归清理；备份锁内取得清单/打开稳定文件句柄，锁外枚举、复制并检查代际。 |
| F05 搜索无用扫描 | 新增独立的下载元数据快照，不枚举正文/图片计算大小。搜索索引由数据库和下载变化更新；关键字变化仅过滤已有索引。 |
| F06 全局变化重算 | 提供按书籍订阅的修订流，阅读器、详情和本地目录只响应对应书籍。历史校正复用进程内目录投影，避免无关书籍变化引起重复文件查询。管理页先发布元数据，精确大小延后 500ms 并合并取消；单一扫描锁限制重叠工作。 |
| F07 重复书名扫描 | 四个 DAO 增加标题修复候选查询；下载使用元数据快照。移除下载/书签/统计页面的重复触发；根导航串行消费合并请求，不因新请求取消、重启当前扫描。备份导入和会话/存储恢复仍可触发修复。 |
| F08 书签封面阻塞观察 | 列表数据库观察只发布数据；封面恢复由独立串行协程处理，按书籍去重，列表变化时取消并等待旧批次退出，再处理最新列表。 |
| F09 封面清理占用事务 | 保留封面维护互斥，但移除包围文件遍历及删除的 Room 写事务，避免与无关数据库写入长时间竞争。封面为可恢复副本，缺失时仍使用现有远端回退。 |
| F10 页面缓存全局锁 | 稳定文件句柄在锁内打开，全文解压与哈希在锁外完成，返回前检查版本。写入先在独立临时文件中压缩，锁内检查 token/epoch/源引用后原子发布。列表快照也提前准备压缩文件；详情通过正文指纹取得源引用，避免再次解压同一 HTML。 |
| F11 离线详情副作用 | 先发布可用的离线详情和合法标题，独立后台修复本地标题；修复失败不影响已显示详情。 |
| F12 云端历史详情门控 | 允许成人内容的模式下先显示可操作的基本历史卡片，详情到达后补封面与进度。关闭成人内容时，未知标记仍等待验证，避免优化绕过过滤。 |

## 一致性约束

- 删除期间阻止该书重新写入、读取索引或复用目录；存储切换/迁移不得与正在进行的递归删除重叠。其他书可继续读写。失败或部分删除后失效元数据及文件清单，等待管理扫描重新核实。
- 元数据列表反映已发布清单，不在每次查询时验证每个文件。应用外移动、删除文件后，通过已有“重新扫描”操作刷新；精确 inventory 扫描会重新检查文件并更新元数据计数。
- 扫描期间发生存储或下载变化时，不缓存旧 inventory，返回新的元数据结果。取消检查按目录/文件执行，提供器正在执行的单次系统调用仍可能需要等待返回。
- 选章预检只缩小此次工作范围，不删除未选章节，也不改变其既有下载状态。全量重新检查仍通过完整扫描/下载目标校验完成。
- 页面缓存清理、登出或新请求使准备中的写入失效；独立临时文件不能把旧内容重新发布。结构化缓存提交时还必须匹配其原始页面引用。
- 公共目录、备份、读取句柄和清单发布继续使用已有存储/删除代际检查；没有修改文件格式、数据库版本或站点协议。

## 更改审查后的修复

1. **删除与恢复互斥**：备份恢复在修改目录前检查活动删除；正在递归删除时拒绝恢复。重复删除同一本书返回未完成，避免把尚未删除的目录当作已成功移除后复用。
2. **迁移先预约再落盘**：选择迁移目录和返回私有目录共用入队流程，先取得存储迁移资格，再保存迁移日志。删除导致预约失败时不写日志；日志写入失败则恢复原有内存迁移状态，避免重启后意外执行未入队迁移。
3. **相同历史快照去重**：在发布 Room 原始记录前排除连续相同的快照，避免无变化的数据库通知把已校正的进度回退；下载修订仍独立触发校正。
4. **封面复制隔离**：补图批次取消后等待同步复制退出，数据库列表继续即时发布。每次复制使用独立临时文件，发布前检查取消，避免旧任务继续写入新任务已发布的封面；观察失败时取消对应补图协程。

## 验证

新增回归测试源码：

- `PageCacheStorageTest`：慢压缩期间其他条目仍可读取/写入；清理之后旧压缩不能发布；源页面替换后准备中的结构化缓存不能发布。
- `StructuredDownloadStoreTest`：选章下载不解析未选章节；元数据快照复用；其他书籍提交不触发当前书的修订观察。
- `NovelTitleDaoInstrumentedTest`：标题修复候选查询保留缺失/占位记录，排除正常标题。
- `LocalHistoryLoadingTest`：先发布记录、存储失败保留内容、旧校正结果不得覆盖新记录；使用保留重复发射的 `MutableSharedFlow` 检查相同 Room 快照不会覆盖校正进度。
- `BookmarkCoverStoreTest`：阻塞旧任务的同步写入，取消后发布另一份完整封面，再释放旧任务；已发布内容保持完整且无临时文件遗留。
- `UserStorageLifecycleInstrumentedTest`：用可阻塞删除的 SAF 提供器检查活动删除时恢复、重复删除和迁移的结果；复制持久化配置模拟重启，确认无意外迁移；删除完成后可恢复原正文。

提交前仅进行静态契约、差异、引用、SQL 结构及 Kotlin 增量语法检查。Kotlin 解析器对部分既有语法有局限，不能代替编译。本地未执行 JVM/设备测试、Gradle 构建或 Lint；没有测量冷启动耗时、帧率或锁等待时间。提交后的验证以对应 GitHub Actions 运行结果为准。

真机验收应覆盖：公共目录冷启动进入书架/历史；长篇小说补少量章节；下载期间连续修改搜索词；阅读与删除/备份并行；批注和书签较多时的更新；成人模式两种设置下的云端历史展示。
