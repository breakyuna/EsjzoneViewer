# 阅读器手势

## 上下滚动布局

正文由 `LazyColumn` 处理跟手滚动和惯性。目录从左侧拉出，当前 ESJ 章节的评论从右侧拉出，二者复用现有内容组件。文库章节不响应评论侧滑。

侧滑采用方向锁定与独立的松手判定：

1. 超过系统触摸容差后只判定一次方向。水平位移必须大于垂直位移的两倍，其他方向优先交给纵向阅读；已开始纵向滚动的手势不会中途变成侧滑。
2. 方向确定后立即按位移拖动实际面板；此时尚未确认展开。面板内的纵向列表仍自行处理滚动。
3. 从关闭状态拉出面板宽度的 40% 后，松手展开；已展开的面板向回拖动 40% 后，松手收回。
4. 同向甩动达到 900dp/s 且整次手势位移至少 32dp，也可以展开／收回；完全收回时不会因末尾速度重新打开。
5. 多指、取消或子控件已接管的手势不提交新的展开状态。长按超时仅在方向确定前检查，已经开始拖动后允许停顿。

左右入口保持全阅读区域可用，不新增屏幕边缘限定。系统边缘返回手势由系统处理。

评论在侧栏内加载、回复和提交，顶部返回按钮与系统返回先关闭侧栏。评论模型按章节归属当前阅读导航条目，关闭再打开保留该章节草稿。评论侧栏可见期间暂停正文阅读计时。

## 左右分页布局

`HorizontalPager` 负责连续跟手拖动、速度追踪和松手吸附。显式配置 `PagerSnapDistance.atMost(1)` 与 `snapPositionalThreshold = 0.5f`：慢拖超过半页后翻到相邻页，未达到则返回原页；甩动由 Pager 按速度决定方向，甩动吸附距离最多一页。

横向平移直接使用 Pager 位移；淡入淡出按翻页进度交叉渐变；覆盖翻页按同一进度让上层页面移入／移出。点击和音量键也驱动同一个 Pager，避免手势和程序动画同时争用页面。

侧边点击和音量键的翻页请求按触发顺序入队，每次独立完成一页；反方向请求不抵消、不合并。单次动画以 180ms 为起点，根据输入间隔和队列积压加速，最短目标时长为 48ms；新请求也能加快正在播放的动画，队列清空后恢复正常速度。系统关闭动画时直接完成每次翻页。实际时间还取决于显示帧率和章节加载。

队列处理期间关闭 Pager 的原生拖动接管，保留外层点击识别，避免再次按下中断动画并吞掉点击。跨章请求留在队首，等目标章节加载、分页及布局锚点就绪后再执行，后续请求继续排队；没有目标页或加载失败的请求不翻页。预加载引起页码变化时按稳定页面键追踪目标；退出阅读、主动跳章、打开设置或改变布局会清理旧队列。

动画期间目标暂时不可用时释放 Pager 滚动锁，通过状态变化等待分页和布局就绪；就绪后继续追踪同一个页面键。目标页面已不存在时结束该请求，避免在滚动锁内逐帧空等。

`ReaderShell` 在系统触摸容差后锁定方向，水平位移必须大于垂直位移两倍才交给 Pager。普通页面的纵向动作提前接管，避免下拉先被横向翻页识别；书签仍需松手满足 `max(96dp, 阅读区域高度 × 12%)` 和纵向位移超过横向 1.5 倍才切换。未达到书签阈值则回弹，上滑不切换书签。超大页面保留其内部纵向滚动优先权。

## 设计依据

- [Compose 手势处理](https://developer.android.com/develop/ui/compose/touch-input/pointer-input/understand-gestures)：触摸容差、事件传递阶段和事件消费；使用 Initial 阶段识别明确侧滑，并尊重已被子控件消费的动作。
- [Compose 拖动与滑动](https://developer.android.com/develop/ui/compose/touch-input/pointer-input/drag-swipe-fling)：通过连续位移驱动界面，松手后动画到稳定位置；距离与速度作为不同判据。
- [AnchoredDraggable 迁移指南](https://developer.android.com/develop/ui/compose/touch-input/pointer-input/migrate-swipeable)：关闭／展开锚点与位置、速度阈值模型。
- [Compose Pager](https://developer.android.com/develop/ui/compose/layouts/pager)：跟手分页、甩动距离约束和基于页面偏移的动画。

方向比 2、40%、32dp 和 900dp/s 是本项目的初始交互参数，不是官方规定值。实现复用 Compose 的指针事件、速度追踪和弹簧动画，额外保留阅读优先的方向仲裁。

JVM 测试检查方向和松手判定、点击队列顺序及加速恢复；设备测试还覆盖动画中连续点击和反向点击、当前动画加速，以及逐页完成。原有设备测试覆盖正文松手前滚动、方向中途改变、双侧内容跟手、侧栏内部滚动、短拖回弹、无评论入口、水平翻页在松手前产生位移、纵向弯折不翻页，以及分页／书签／超大页面滚动互不干扰。实际设备上的手感和系统返回交互需要设备验收。
