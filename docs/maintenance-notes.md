# 维护注意事项

以下记录原静态审计中仍值得复查的观察项；仅说明源码路径，不代表已在设备上复现或确认当前仍是缺陷。

- `StartupCoordinator.retry()` 直接写入 Starting，失败后快速重复重试的状态转换可在修改启动流程时重新检查。
- `SettingsStateBoundary` 的 `boundRepository` 在锁外快速读取、锁内再次检查；如改变绑定线程或 repository 生命周期，应重新审视可见性。
- 旧 Room 的 `theme` 键会在迁移后删除；若需要支持很旧版本的主题偏好升级，应先核对旧版本的值和迁移语义。
- 阅读设置使用进程级协程进行 250ms 防抖保存；在防抖期间进程被终止时，最后一次调整可能未落盘。

存储性能优化保留以下一致性原则：

- 书架和历史优先发布可用的本地数据；后台进度校正不得覆盖较新的阅读位置。
- 下载只预检此次目标章节；删除、存储迁移和备份恢复应维持代际检查及互斥关系，阻止旧任务重新发布数据。
- TXT 和 EPUB 导出由应用进程持有，退出小说详情页后继续写入系统文件选择器提供的目标。进程终止后导出无法续跑。EPUB 逐章读取、打包正文，旧版章节在内存中解码，导出期间无需回写。EPUB 在清理行首空白前识别行内标签中的换行和段首缩进，拆段时保留两侧文字的样式和链接。导出保留有序列表的编号类型，内置样式仅限制封面和插图宽度并保留比例。导出依次尝试本地图片缓存（含详情页列表入口的封面）、下载目录和书架缩略图；候选封面按文件头识别格式并读入后再写入 ZIP，找不到可用封面时以书名和作者生成封面页。
- EPUB 正文插图按文件头识别 PNG、JPEG、GIF 和 WebP，统一生成归档扩展名和 OPF 媒体类型。格式无法识别的图片沿用现有文字占位。富文本插图保留原有替代文字，缺少 `alt` 时填入通用说明。
- 页面缓存的锁外读写必须在发布前校验请求令牌、代际和来源版本；缓存淘汰不得删除正式下载。
- 隐藏成人内容时，云端历史中分类未知的作品应等待验证，不能把未知当作已确认的非成人内容。

安全与资源预算边界：

- 外部小说入口、导航消费入口和详情 API 只接受可信镜像的默认端口详情路径，自动升级 HTTP 链接并剥离 `query` 与 `fragment`，拒绝 `userinfo` 及非数字小说 ID。
- ZIP 恢复拆分流处理预算与磁盘写入预算：流解压总量上限 16 GiB、落盘上限 `min(16 GiB, 可用磁盘 - 64 MiB)`，最多 200,000 条目（跳过项和目录项均受流上限与取消检查约束但不计入磁盘配额）；`backup.json` 与单个下载 JSON 解压流上限 32 MiB，JSON 嵌套最多 64 层、500,000 token。
- 备份恢复在发布下载文件前校验结构化章节的正文指纹与文本长度。日常打开缓存或离线章节时校验块结构和字段格式。
- 人名替换对正则规则使用预编译缓存的 RE2/J（不支持前后查找与模式内反向引用），普通纯文本规则直接字符串匹配，限制规则数、长度、单规则匹配次数与输出上限（单规则超限时仅隔离该规则，避免整段所有规则失效）；网页繁简转换跳过纯空白节点并支持批量打包调用，按单次（32,768 UTF-16 单元 / 每批 256 项、256 Ki 单元）与单页额度（8 Mi 单元 / 4,096 次，翻页重置）限制，关闭浏览器后停用桥。
- 图片客户端在解压后累计响应字节（上限 32 MiB，普通 60s / Wenku 120s），读取期间持续校验至少 64 MiB 可用磁盘；Wenku 普通私有偏好 `wenku8_cookies` 仅保存允许的 Cloudflare 过盾 Cookie。检测到旧加密偏好键时清空重置，同时在读取时清理过期及其他 Cookie。
