# 平板横屏布局

宽屏分支使用导航栏和系统边距扣除后的页面尺寸：可用宽度至少 840 dp、高度至少 480 dp、宽大于高，且按字体缩放折算后的宽度至少 760 dp。竖屏、窄分屏和低矮手机横屏继续使用原有布局；大字体空间不足时也回到原有布局。

- 导航：横屏侧栏在子页面保持可用，各 Tab 保留自己的返回栈；编辑模式继续按原有规则隐藏导航。阅读器仍使用独立根页面。
- 首页：书籍按可用宽度排为 4～8 列；热门轮播同时显示两张卡片，并提供前后切换按钮。成人过滤、每区数量、下拉刷新、上拉加载和封面预取沿用原有规则。
- 小说详情：左栏独立滚动书籍信息、标签、阅读/收藏/下载操作和简介，右栏独立滚动章节与评论。评论编辑器和清理反馈仍位于两栏之外；紧凑页面保持原有单列顺序。
- 搜索、分类结果、历史、书签、下载、书架：记录在宽度足够时并排排列，标题、筛选、错误和分页保持通栏。封面网格在宽屏采用更大的最小单元宽度；书架切换列表/网格继续按作品身份定位。
- 自适应记录列表切换列数时，按首个可见记录的身份重新定位行并保留行内滚动偏移；Activity 重建时同样保存该身份，标题与筛选等通栏项不参与记录行索引换算。
- 设置：左侧直接切换常规、导航、阅读、下载、存储和关于，右侧复用原有设置内容和各分区的保存状态。系统返回仍先回常规，再退出设置。
- 个人中心与统计：账户和工具并排；统计总览通栏，图表面板并排。
- 阅读：仅在宽屏限制滚动正文和底部工具栏的最大宽度，并扩大目录、评论侧面板。分页计算、点击翻页、手势、书签和阅读位置逻辑不变。

新增 `WideLayoutPolicyTest` 检查布局启用范围、字体缩放和列数；`WideNovelDetailInstrumentedTest` 检查独立滚动及紧凑单列。测试源码已补充，未运行。

`AdaptiveListAnchorInstrumentedTest` 覆盖一至三列切换、记录重排、状态恢复、短列表和可见筛选栏的滚动锚点。测试源码已补充，未运行。
