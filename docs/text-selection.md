# 阅读器以外的文字选择与复制

阅读器正文的原生选择和“长按划线”见 [reader-gestures.md](reader-gestures.md)。其他页面的只读正文统一用 `ui/component/SelectableText.kt` 中的 `SelectableProse`（Compose `SelectionContainer`）包裹，长按选择、拖动手柄调整后用系统菜单复制。

## 原则

- 只包裹正文文字本身，不包裹带 `clickable`／`combinedClickable` 的整行、卡片或按钮。选择手势同样依赖长按，放到可长按的行上会抢走多选或菜单。
- 选择区内的链接（`LinkAnnotation`）仍按原逻辑点击打开；长按链接文字进入选择。
- 复制得到的是当前显示的文字：已按全局繁简设置转换，注音只保留正文，图片不复制。
- 不能直接选择的位置提供整段复制：长按复制完整纯文本，Android 13 及以上由系统显示剪贴板提示，更低版本显示 Toast。

## 各页面取舍

| 页面／区域 | 处理 | 原因 |
| --- | --- | --- |
| 书籍详情简介（展开或无需展开） | `SelectableProse` 包裹完整简介，可跨段落选择 | 简介区域没有其他手势 |
| 书籍详情简介（折叠预览） | 点击仍展开；长按复制完整简介（`NovelDescription.copyText()`，保留段落和换行） | 折叠预览整块可点击且被截断，选择会与点击展开冲突，也只能选到可见部分 |
| 评论卡片（书籍评论、章节评论、阅读器评论侧栏、论坛帖子回复） | 正文、引用分别可选；作者、时间、楼层、回复按钮不在选择区内 | 卡片本身没有点击或长按，回复按钮保持独立 |
| 论坛帖子正文 | 标题、作者行和正文同一选择区，可跨段落选择 | 帖子卡片没有行手势 |
| 个人中心资料卡 | 用户名、经验和等级可选 | 资料卡没有点击；头像和重试按钮不在选择区内 |
| 书架、观看记录、书签、划线列表 | 不加选择 | 行有点击打开和长按多选／编辑；划线、书签摘录可在阅读器内选择 |
| 书籍详情标题、作者、标签 | 不加选择 | 标题与作者带共享元素转场，标签可点击搜索 |
| 阅读器正文 | 保持原有逻辑 | 由阅读器设置控制原生选择或长按划线 |

`tools/qa/verify_static_contracts.py` 检查上述正文页面仍使用 `SelectableProse`，并禁止在书架、观看记录、书签和划线列表页面引入文字选择。后续新增的会员中心正文（系统消息、我的回复等）也应使用 `SelectableProse`，可点击跳转的列表行保持不选。
